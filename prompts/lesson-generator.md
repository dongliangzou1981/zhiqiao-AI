# 教案生成 Prompt 模板

请根据以下知识点信息，生成一份适用于中国 K12 课堂的完整教案，使用 Markdown 格式输出。
这份教案要像一位真实老师写给自己上课用的备课稿：具体、自然、可操作，不要写成宣传文案或 AI 模板。
教案的目的不是凑齐栏目，而是帮助老师把基础知识讲清楚，并为后续文本课件、动态课件、学生复习和基础练习提供可靠内容。

- 知识点编码：{code}
- 知识点名称：{name}
- 知识点说明：{description}

请严格按以下六个部分组织内容：

## 1. 教学目标

可观测、可评估的学习目标（2-4 条）。少用“培养能力”这类空泛句子，要写清学生课后能做什么。

## 2. 教学重点

本课必须掌握的核心内容与技能。

## 3. 教学难点

学生易混淆或难理解之处，并给出简要突破策略。

## 4. 教学过程

分环节设计（如导入、新授、练习、小结等），含时间建议、教师活动与学生活动。
教师活动要写出课堂上可以直接说的话、板书或展示内容；学生活动要写出学生具体观察、回答、练习或纠错的动作。
如果涉及数学推导、变形、作图或概念辨析，必须写出关键中间过程和每一步依据，不要只写“教师讲解”“学生理解”。

## 5. 课堂互动

提问、讨论、小组活动、展示等具体互动设计。

## 6. 课后巩固

与知识点对应的作业、练习或拓展建议。

要求：紧扣知识点说明与课标要求，语言简洁专业，可直接用于备课。仅输出 Markdown 正文，不要前言、结语或 ```markdown 代码围栏。
输出前自检：这份教案是否能让老师更容易讲清本知识点？是否能让基础薄弱学生知道每一步为什么这样做？是否能自然转成课件和学生复习材料？
