# K12 知识库数据补全机制

## seed 示例数据的作用和限制

`supabase/add-k12-knowledge-base.sql` 中的 seed 数据只用于验证数据模型和知桥现有功能接入方式。它能证明初中数学小样本可以支撑教案生成、学生答疑和后续课件闭环，但不能代表完整教材覆盖，也不能替代教研审核。

seed 的限制：

- 覆盖范围很小，只包含初中数学七年级上册的少量知识点。
- 知识点关系、常见错误和题目都是样例级，不是全量教研成果。
- 不适合直接作为正式学科内容库的完整依据。
- 后续扩展必须进入“暂存、审核、入库”的数据流程。

## 后续补全数据的三种方式

### 后台表单录入

适合少量高质量知识点、常见错误和教学资源的人工维护。老师或教研人员通过后台表单录入后，应先进入暂存区，由审核人确认编码、章节、课程标准引用和内容质量，再写入正式库。

### Excel / CSV 批量导入

适合按教材章节批量补全知识点、题目、常见错误和资源。导入脚本只负责解析和规范化字段，结果写入 `external_knowledge_items` 或 `external_question_items`，不直接写入 `knowledge_points` 或 `question_bank`。

### 外部开源库导入

适合未来接入 EDUKG、OpenKG、Math23K、APE210K、K12-KGraph 等外部数据。外部数据必须记录来源、授权、允许用途和原始 payload，先进入外部暂存表，经过去重、匹配和人工审核后，才允许进入正式库。

## 为什么外部开源库不能直接进入正式库

外部开源库的数据结构、版权边界、知识点粒度和教学表达不一定符合知桥的课程标准主线。直接写入正式库会带来四类风险：

- 版权和授权风险：不同数据集允许用途不同，不能默认用于商业或学生端展示。
- 课程标准偏差：外部知识图谱可能不按中国 K12 教材章节组织。
- 质量风险：题目答案、解析和知识点映射可能存在错误。
- 污染主库：一旦批量导入错误，后续教案、课件、答疑和学情都会受影响。

因此外部数据只能先进入暂存库，通过审核记录形成可追溯链路。

## 正式库、暂存库、审核流程的关系

- 正式库：`knowledge_points`、`question_bank`、`common_mistakes`、`teaching_resources` 等，直接服务教案、课件、答疑和复习。
- 暂存库：`external_knowledge_items`、`external_question_items`，保存外部或批量导入数据的原始内容、规范化字段、建议匹配和置信度。
- 来源和任务：`external_sources` 记录数据来源与授权；`external_import_jobs` 记录每次导入的文件、状态和统计。
- 审核记录：`external_mapping_reviews` 记录审核动作、目标表、目标 id、审核人和备注。

流程：

1. 登记外部来源或批量导入来源。
2. 创建导入任务。
3. 解析文件或外部数据，写入暂存项。
4. 自动建议学段、学科、年级、知识点映射和置信度。
5. 人工审核通过或拒绝。
6. 通过项再由后续入库工具写入正式库，拒绝项保留原因。

## 小学、初中、高中补全顺序建议

建议顺序不是一次性铺开全学段，而是按当前产品闭环优先级推进：

1. 初中数学：与现有教案、课件、反馈和复习闭环最贴近。
2. 初中其他核心学科：语文、英语、物理、化学可按试用反馈决定。
3. 小学数学和语文：需要调整表达方式和题目难度，不宜直接复用初中模板。
4. 高中数学和理科：知识点依赖更强，题目复杂度更高，应等审核和题库机制稳定后再推进。

## 初中数学优先补全路线

第一阶段建议只扩“人教版七年级上册”：

1. 完整补齐章节树和知识点编码。
2. 每个知识点补 `summary`、`learning_objective`、`teaching_focus`、`teaching_difficulty`。
3. 每章补常见错误和基础题。
4. 建立前置、后继、相关和易混淆关系。
5. 对每章抽样生成教案、课件和学生答疑，标记 A/B/C/D 质量等级。
6. 稳定后再扩七年级下册、八年级、九年级。

## 未来外部数据源接入位置

- EDUKG / OpenEDUKG：优先进入 `external_knowledge_items`，用于候选知识点、知识点关系和概念解释。
- OpenKG：作为通用图谱补充，只导入教育相关节点和关系。
- Math23K：优先进入 `external_question_items`，用于数学应用题暂存和知识点匹配。
- APE210K：优先进入 `external_question_items`，用于更大规模数学题暂存，不直接进入正式题库。
- K12-KGraph：优先进入 `external_knowledge_items`，用于课程知识图谱候选关系。

所有外部数据源都必须先在 `external_sources` 登记授权与允许用途，再通过 `external_import_jobs` 形成可追溯导入批次。
